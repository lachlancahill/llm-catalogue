# 0012 — GPT-6.2 Astra, and what the ChatGPT plan serves

- Date: 2026-11-18
- Status: accepted

## Context

Right after 6.2 Sol (0011), Lachlan asked whether his ChatGPT plan covers Astra or Astra
for Law, then asked for Astra in the catalogue. OpenAI lists two Astra models,
`gpt-6-astra` and `gpt-6.2-astra`. Only the current one, 6.2, is added, as with Sol.

## Decision

**`openai:gpt-6.2-astra` joins.**

- **Prices** (pricing page and model page, 2026-11-18): $8 in, $0.40 cached (0.05x),
  $10 cache write (1.25x, 30 min), $40 out. Above 272K input tokens, $16 / $60. Four times
  6.2 Sol at every tier. Fast and Ultrafast tiers exist at 2x and 3x (6x from 2027-03-01);
  the catalogue records Standard, as for every OpenAI model.
- **Window**: 922,000 input (1,050,000 context, 128,000 output), from the model page.
  Knowledge cutoff 2026-05-18.
- **Measured on `/v1/responses`**, the probe from 0011, one sample each. Every fact matches
  6.2 Sol:

  | Effort | Result | Reasoning tokens |
  |---|---|---|
  | unset | echoed back as `medium`, 3 calls | 0 |
  | `none`, `minimal` | 400: "Supported values are: 'low', 'medium', 'high', 'xhigh', and 'max'" | |
  | `low` | 3 calls | 0 |
  | `medium` | 3 calls | 6 |
  | `high` | 3 calls | 9 |
  | `xhigh` | 3 calls | 15 |
  | `max` | 3 calls | 19 |

  Temperature 0.5 is a 400. The test image was described in full. On Chat Completions, tools
  with an effort are a 400. Replay is counted: 200 prompt tokens without call 1's 9 reasoning
  tokens and 211 with them, `reasoning.context='all_turns'`.

## What the ChatGPT plan serves (2026-11-18)

One streamed "reply ok" call each, through the shared plan connection, with no fallback:

- Served: `gpt-6.1-sol`, `gpt-6.2-sol`, `gpt-6-astra`, `gpt-6.2-astra`.
- **Not served: `gpt-6.2-astra-law`** (Astra for Law): 400, "not supported when using Codex
  with a ChatGPT account". It is not on the API key either (`model_not_found`). OpenAI offers
  it to ChatGPT Enterprise customers through its Trusted Access Program. It has a row on the
  pricing page at Astra's prices, so it can be added once a key can reach it.

## Consequences

- Astra's effort counts on this small prompt are lower than Sol's. That does not mean it
  reasons less on real work. One sample each, as in 0009 and 0011.
- `gpt-6-astra` is not catalogued. Add it only if an app wants it.
- No full refresh this session (no Anthropic or Together key); see 0011.
