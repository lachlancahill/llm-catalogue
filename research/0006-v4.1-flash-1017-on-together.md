# 0006 — V4.1-Flash-1017 on Together

- Date: 2026-10-20
- Status: accepted

## Context

0004 left Together out because it did not list 1017 on 2026-10-18. On 2026-10-20 Lachlan
reported it listed, and `/v1/models` confirmed `deepseek-ai/DeepSeek-V4.1-Flash-1017`.
0004 had already decided it would be probed separately when it appeared (wandly 0156:
a gateway twin inherits nothing).

## Decision

Add `together:deepseek-ai/DeepSeek-V4.1-Flash-1017` as its own entry, measured from
scratch with `probe_model.py` and `probe_images.py`. It sits beside the DeepInfra entry,
and no app's default changes (0005's default stays the DeepInfra key).

| Fact | Together | DeepInfra (0004) |
|---|---|---|
| Billed in / out | 0.30 / 1.20 | 0.098 / 0.294 (0.51 off 0.20 / 0.60) |
| Cache read | 0.02x | 0.03x |
| Ladder | `none`, `high`, `max` | `none`, `low`, `high`, `max` |
| Unset | **on**, `below_max` | off |
| Replay | dropped; `thinking` is a 400 | dropped |
| Tools, temperature, images | yes, yes, yes | yes, yes, yes |
| Reports cost | no | yes |

The sweep was 5 samples a level, alternating, with the 64,000 ceiling, on the
documented levels (`low`/`high`/`max`). Medians in reasoning characters were unset
3,241, `low` 2,343, `high` 4,706 and `max` 23,346, and `none` was 0 in 5 of 5. All 25
answers were correct, and none hit the ceiling.

- **`low` is not on the ladder.** `high` was longer than `low` on 17 of 25 pairs. One
  `low` run thought for 11,898 characters, more than any `high` run.
- **`high` to `max` separates, but not wholly.** `max` was longer on 24 of 25 pairs. The
  exception was a 5,136-character `max` run against `high`'s 7,453.
- **Unset is on.** Unset was shorter than `max` on 23 of 25 pairs. 0002 calls that
  `below_max`. Against `high` it is indistinguishable, but it is not recorded as `high`,
  because nothing documents that as Together's default.

## Why

A gateway twin can differ from the original, and this one does. The same checkpoint
under the same name has a different unset behaviour and a shorter ladder. Copying
DeepInfra's flags would have told an app that sending nothing turns reasoning off, and
that `low` is a real step. Both would have been wrong on Together.

## Alternatives considered

- **Inherit DeepInfra's entry with Together's prices.** Rejected for the reason above.
- **More samples to place `low`.** At 17 of 25 it is far from separating, so more
  samples would not plausibly put it on the ladder. If an app ever offers `low` on
  Together, it should measure it there first.
- **Run the full refresh.** It still needs Anthropic and OpenAI keys this shell lacks.
  The row was written with refresh's own `_together` reader in `measured.py`'s order,
  and the existing Together GLM-5.3 row was checked against the live listing with no
  drift.

## Consequences

- An app that moves 1017 from DeepInfra to Together must **send `none` to get no
  reasoning**. Sending nothing now thinks, which adds latency and output tokens.
- Together is the expensive pair: 3x the prompt and 4x the completion price of
  DeepInfra's promotion, and 1.5x / 2x even after the promotion ends. It is a fallback
  for DeepInfra's dropped streams (0005), not a cheaper home.
- Together reports no cost, so an app must compute it from these prices.
- `probe_model.py` now logs a replay control that a gateway rejects, instead of
  crashing on it. Together 400s on `thinking` because it reads it as its own object
  and wants a `type`.
