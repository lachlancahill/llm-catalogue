# 0009 — GPT-6.1 Terra, and Sol's images and temperature

- Date: 2026-10-27
- Status: accepted

## Context

Lachlan asked to bring the apps' OpenAI models up to the 6.1 line: Sol and Terra. The
catalogue had `openai:gpt-6.1-sol` (0007, 0008) but not Terra. OpenAI's model list on
2026-10-27 has `gpt-6.1-sol` and `gpt-6.1-terra`, and **no `gpt-6.1-luna`** (404), so
Luna stays on 5.6. The only app on 5.6 Sol or Terra was chat; legal and wandly were
already on 6.1 Sol.

## Decision

**`openai:gpt-6.1-terra` joins**, with its facts from its own pages and its own probe:

- **Prices** (pricing page, 2026-10-27): $1 in, $0.05 cached (0.05x), $1.25 cache write
  (1.25x, 30 min), $5 out. Above 272K input tokens, $2 / $7.50. Half Sol's price, and
  a quarter of 5.6 Terra's output price.
- **Window**: 922,000 input (1,050,000 context, 128,000 output), from the model page,
  the same as Sol.
- **Measured by hand on `/v1/responses`** with `store=False`, one sample each, the tool
  prompt from 0008 (arithmetic, then three parallel `get_weather` calls):

  | Effort | Result | Reasoning tokens |
  |---|---|---|
  | unset | echoed back as `medium`, 3 calls | 22 |
  | `none` | 3 calls | 0 |
  | `minimal` | 400: "Supported values are: 'none', 'low', 'medium', 'high', 'xhigh', and 'max'" | |
  | `low` | 3 calls | 17 |
  | `medium` | 3 calls | 20 |
  | `high` | 3 calls | 33 |
  | `xhigh` | 3 calls | 101 |
  | `max` | 3 calls | 158 |

  So the ladder is `none` to `max`. **Terra accepts `none`, which Sol rejects**: an app
  copying Sol's menu onto Terra loses `none`, and copying Terra's onto Sol 400s.
- Temperature 0.5 is a 400. The test image (green, red circle, 47) was described in full.
  On Chat Completions, tools with an effort are a 400, so `tools_need_responses_api`.
- **Replay counted**: the follow-up's prompt was 194 tokens without call 1's 25 reasoning
  tokens and 221 with them; output 61 against 40.

**GPT-6.1 Sol gains `supports_temperature=False` and `supports_images=True`**, measured the
same day: temperature is a 400 and the image was described. Both were None before, so an
app reading `supports_images` would have offered no image upload on Sol.

**The 5.6 entries stay.** Neither is deprecated, and Luna has no 6.1 successor. An app
that moves off them simply stops naming them.

## Consequences

- Effort levels are one sample each, with tiny reasoning counts. The ladder is the
  documented one, which OpenAI bills per level. This is not a claim that each level
  separates on a real workload.
- `probe_model.py` still does not cover `/v1/responses` (chat 0057). These were measured
  with a throwaway script, as 0007 and 0008 were.
