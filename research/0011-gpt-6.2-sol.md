# 0011 — GPT-6.2 Sol

- Date: 2026-11-18
- Status: accepted

## Context

OpenAI released `gpt-6.2-sol`, and Lachlan asked for it in the catalogue. OpenAI's model
list on 2026-11-18 has `gpt-6.2-sol` and `gpt-6.2-astra`, plus the 6.1 Sol and Terra
already catalogued. There is no 6.2 Terra.

## Decision

**`openai:gpt-6.2-sol` joins.** On every fact measured it matches GPT-6.1 Sol, so an app can
change the model name and keep its effort menu as it is.

- **Prices** (pricing page and model page, 2026-11-18): $2 in, $0.10 cached (0.05x),
  $2.50 cache write (1.25x, 30 min), $10 out. Above 272K input tokens, $4 / $15. The same
  as 6.1 Sol, whose row on the page has not changed. Its `price_source` carries its own date,
  because the shared OpenAI date (2026-10-15) is older than this read.
- **Window**: 922,000 input (1,050,000 context, 128,000 output), from the model page.
  Knowledge cutoff 2026-06-01.
- **Measured by hand on `/v1/responses`** with `store=False`, one sample each, the tool
  prompt from 0008:

  | Effort | Result | Reasoning tokens |
  |---|---|---|
  | unset | echoed back as `medium`, 3 calls | 6 |
  | `none` | 400: "Supported values are: 'low', 'medium', 'high', 'xhigh', and 'max'" | |
  | `minimal` | 400, same message | |
  | `low` | 3 calls | 0 |
  | `medium` | 3 calls | 6 |
  | `high` | 3 calls | 15 |
  | `xhigh` | 3 calls | 21 |
  | `max` | 3 calls | 110 |

- Temperature 0.5 is a 400. The test image (green, red circle, 47) was described in full.
  On Chat Completions, tools with an effort are a 400, so `tools_need_responses_api`.
- **Replay counted**: the follow-up's prompt was 200 tokens without call 1's 15 reasoning
  tokens and 217 with them; output 36 against 63 without them. The response reports
  `reasoning.context='all_turns'`.

**6.1 Sol stays.** It is not deprecated, and moving an app to 6.2 is that app's decision.
